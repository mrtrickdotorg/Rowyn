# Skips expected from the Python contract suite: the reason each test reports
# and the guard that makes the skip legitimate.
#
#   TEST<TAB>GUARD<TAB>REASON
#
# build/validate.sh fails when a test skips with a reason that is not listed
# here, when a test skips while none of its guards applies (a fixture that
# failed to build looks nothing like a host that cannot run it), and when a
# listed test does not skip while its guard still applies (a deleted test, or
# an expectation that no longer describes the suite). Reasons are compared
# verbatim.
#
# Guards are ORed: the test must skip while any one of them holds, and must run
# once none does.
#   env:VAR      the variable is unset or empty
#   optin:VAR    the variable is not "1"
#   absent:PATH  PATH does not exist below the repository root
#   tool:NAME    NAME is not on PATH
#   nonroot      the suite is not running as root
#
# Regenerate after an intentional change:
#   python3 -B build/tests/rowyn_run_suite.py /tmp/skips
#   cut -f1,3 /tmp/skips        # then add the guard each entry needs
#
# Most entries are pinned-source integration tests: they need
# ROWYN_TEST_UPSTREAM_REPO pointing at the pinned upstream checkout, so they
# skip on a plain `./build/validate.sh` and run when it is supplied. The
# Ubuntu fixture tests need their ROWYN_TEST_UBUNTU_* opt-in, the retire-spike
# test needs root, and the update-channel test reads the generated
# hub-source/ tree. test_update_policy's containers/image tests need skopeo
# (the CI validate job installs it) and are deliberately absent: a host
# without skopeo must fail validation rather than silently stop checking the
# update policy.
